# Homebrew Tap for Dusty

Official Homebrew tap for [Dusty](https://dustystorage.com) — the AI-explained macOS storage cleaner and 1-click app uninstaller.

## Installation

```bash
brew install sarmadhussainch/dusty/dusty
```

Or tap first:

```bash
brew tap sarmadhussainch/dusty
brew install --cask dusty
```

## Updates

```bash
brew upgrade --cask dusty
```

## Uninstall

```bash
brew uninstall --cask dusty
```
